What is this App?

This app verifies whether references are real or not. It produces a report that details the likelihood that a reference is real.

How To Process References

There are two ways to process references.

Automatic Method

This method is designed to work with PDF documents that have a dedicated reference section, documents with no such section should be proessed with the manual method

  1. Press the 'Select File' button and upload a file
  2. Press the 'Process File' button
  3. Review and correct the extracted references in the 'Reference Editor' dialogue box

Manual Method

  1. Press the 'Paste Reference' button
  2. Paste references into the 'Reference Editor' dialogue box

After choosing either one of these steps, the references will be processed and a report will be produced.

What Is In The Report?

The report lists every extracted reference along with a colour coded verdict and confidence score ranging from 1 to 0. References are asigned their verdict depending on what threshold the score falls into.

Reference elements with errors are shown along with the expected element value, matching elements are shown alone.

Verdict Score Threshold Description
REAL ≥ 0.80 Likely real, the reference contains no major errors.
UNSURE ≥ 0.60 and < 0.80 Could either be real or fake, the reference may contain small errors.
FAKE < 0.60 Likely fake, the reference may contain major errors.

The report can be saved as a .pdf, .html and/or .csv file in ~/Documents/refreport and/or shown in the GUI, depending on the user settings.

What Settings Can I Change?

You can change settings related to backend services and the type of generated report. This dialogue box can be accessed via the 'Settings' button.

How Do I Setup The Database and API Keys?

The database is located in data/localpapers.db, if a database doesn't already exist one is automatically created.

The API keys and other secrets are stored in src/.env, Semantic Scholar requires an API_KEY and Crossref is better with an EMAIL. Both of these variables can be added to src/.env
